# 🚀 Momentum — Personal Life & Career Tracker

A single-page web app I built to track my daily habits, DSA/LeetCode progress,
study time, English practice, health (water, weight, mood, medicine, skin & hair
care) and my 16-week Java Full-Stack roadmap — with weekly, monthly and yearly views.

**Live demo:** enable GitHub Pages, then your link appears here → `https://<your-username>.github.io/momentum-tracker/`

## ✨ Features
- 🔥 Daily habit tracking with streaks, progress ring & confetti
- 📊 Daily / weekly / monthly / yearly charts (Chart.js)
- ⏱️ Pomodoro focus timer + DSA problem counter
- ✅ To-do list, English journal, water/weight/mood logging
- 💊 Tablet reminders + 🧴 skin care / 💇 hair care tracking
- 🗺️ 16-week study roadmap (Core Java → Spring Boot → Microservices → DSA)
- 🏅 Badges, GitHub-style heatmap, dark/light theme, share card
- ☁️ **Cloud sync** via a free Supabase database (data on every device)

## 🛠️ Tech
- Frontend: HTML, CSS, vanilla JavaScript, Chart.js (single file, no build step)
- Cloud storage: Supabase (PostgreSQL) via REST — keys stay in the browser, not in the repo
- Optional local backend: ASP.NET Core minimal API + SQLite

## ▶️ Use it
Just open `index.html`. Click **☁️ Cloud Sync** to connect your own free Supabase
database (setup guide in the main project). Without cloud, it still works and saves
in your browser.
